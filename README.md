# Dhanush Movva - Portfolio

Business Intelligence & Data Engineer portfolio with a narrated animated introduction, project architecture diagrams, an interactive skills section, and experience.

Live site: https://dhanushmovva-glitch.github.io/Dhanush_Movva/

This is a static GitHub Pages site published from the main branch root. Preview with `python -m http.server 8000`.

Content: `index.html`. Styles: `style.css`. Interactions and project stories: `script.js` and `motion.js`. Narration timing: `intro.js`. Animated illustrations: `intro-scenes.js`. Local voice recording: `assets/audio/dhanush-intro.m4a`.

Illustrative application screens are not employer screenshots. Product asset sources are recorded in the assets directories.
